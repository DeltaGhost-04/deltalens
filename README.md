# DeltaLens

**Open data for building better Delta communities.**

DeltaLens is an open-source mapping and data platform focused on vacant properties, redevelopment opportunities, and community infrastructure across the Mississippi Delta.

## Mission

Help residents, researchers, planners, and local leaders better understand community conditions through accessible geographic data and interactive maps.

## Initial Focus

The first release will focus on identifying and documenting potential redevelopment opportunities using verifiable public information.

### Planned Features

* Interactive map of the Mississippi Delta
* Property and parcel data exploration
* Documentation of potential redevelopment sites
* Filters for location and property status
* Data source and update-date tracking
* Community infrastructure layers

## Technology

* Python and FastAPI
* React
* Leaflet
* PostgreSQL and PostGIS
* GeoPandas

## Development Principles

* Use documented, traceable data sources.
* Distinguish verified records from unconfirmed observations.
* Never label a property vacant or abandoned without adequate evidence.
* Respect privacy and avoid exposing unnecessary personal information.
* Make data limitations clear to users.

## Status

Early development. The initial milestone is a working interactive map with a documented sample dataset.
